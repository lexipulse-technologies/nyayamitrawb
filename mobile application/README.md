# NyayaMitra - Up-To-Date Trilingual Civil Legal Navigator for India

**NyayaMitra** is a free, up-to-date, trilingual civil legal navigator for India, specifically designed for West Bengal. It provides comprehensive civil legal guidance across 300 workflows, official government portal links, an E-Library of bare acts, document drafting services, and advocate consultations — all in English, Bengali, and Hindi.

---

## 🌟 Key Features

| Feature | Description |
|---------|-------------|
| **🆓 Free & Up-to-Date** | Completely free civil legal navigator with up-to-date information |
| **🌐 Trilingual Support** | Available in English, বাংলা (Bengali), and हिन्दी (Hindi) |

## 📱 Mobile Application

Download the Android app: **NyayaMitra-v1.0.0.apk**

**Version:** 1.0.0  
**Platform:** Android (API 24+)  
**Size:** ~220 MB  
**Package:** `in.nyayamitrawb`

### Installation
1. Download the APK file
2. Enable "Install unknown apps" in Android Settings
3. Open the downloaded APK and install
4. Open NyayaMitra from your app drawer

### Features in Mobile App
- Full feature parity with website (except admin panel)
- Native splash screen with legal-themed audio
- Trilingual persistence (English/Bengali/Hindi)
- Offline detection with network status banner
- Secure E-Library PDF viewer (no download/copy/paste)
- Razorpay payment integration (₹99/₹199/₹499)
- Exit confirmation dialog
- Google Play Billing exempt — real-world advocate services
